🔍 WHAT IT DOES:
═══════════════════════════════════════════════════════════════════════════════════

PHASE 1: Network Reconnaissance
  • Scans target subnet with Nmap
  • Discovers active hosts
  • Identifies open ports and services
  • Detects service versions

PHASE 2: Vulnerability Assessment
  • Maps services to known vulnerabilities
  • Assigns risk levels (CRITICAL/HIGH/MEDIUM/LOW)
  • Generates security recommendations

PHASE 3: Credential Testing (Optional)
  • Tests default credentials on services
  • Attempts common password patterns
  • Reports successful breaches

PHASE 4: Report Generation
  • Exports findings as JSON
  • Timestamped results
  • Ready for analysis/remediation
